# Library Management System

## Overview
A SQL-based Library Management System designed to manage books, members, issue records, and returns efficiently.

## Features
- Add and manage books
- Register members
- Issue books
- Return books
- Track overdue books
- Generate reports

## Database Design
Tables:
- Books
- Members
- Issues
- Returns

## Technologies Used
- SQL
- MySQL
